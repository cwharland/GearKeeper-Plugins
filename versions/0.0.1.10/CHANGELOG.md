# GearKeeper 0.0.1.10

- Use **Store from bags** to deposit eligible, unmodified surplus gear while the in-game Armoire storage window is open.
- Browse Surplus under **Armoire**, **Glamour**, and **Other**. Use **Store from bags** directly from the Armoire group.

- Give Storage horizontal views, readable gear tables, and one selected-item detail pane. Narrow windows use a location picker.

- Storage now shows pending moves by location, with a separate list of verified surplus gear and an explicit Armoire retrieval queue.
- Make Overview easier to scan and add spacing to the priority-job picker. Level 100 jobs are disabled.
- Selecting or deselecting Scholar or Summoner does the same for the other job when both are available.
- Choose priority jobs per character in **Overview → Edit priority jobs**. The picker lists combat jobs by role with their current levels.
- Refresh the in-game UI with a dark blue palette, highlighted tabs, and a two-column job picker with aligned levels.
- Overview shows each priority job’s first AutoDuty item-level or weapon blocker, including known Armoire gear and pieces to retrieve along the way.
- Storage previews eligible Armoury gear for non-priority jobs. Duties without an item-level requirement no longer have an artificial per-slot floor.
